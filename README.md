# Epic Icon Center — Website Redesign

A ground-up redesign of the Epic Icon Center website: a 6,000 sq ft creative and industrial
event venue in the Downtown Los Angeles Arts District.

> "It's your world, We just make it Iconic"

## Stack

Vanilla HTML, CSS and JavaScript — no build step, no dependencies, no external APIs.

## Structure

```
index.html      Home: hero, the space, about, services, packages, add-ons, gallery preview, contact
gallery.html    Full gallery with category filters and a keyboard-accessible lightbox
css/styles.css  Design system (tokens, layout, components, responsive rules)
js/main.js      Sticky header, mobile nav, scroll reveal, form validation, gallery filter + lightbox
favicon.svg     Site mark
robots.txt      Crawler directives
```

## Running locally

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
